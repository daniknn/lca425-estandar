# lca425-estandar

El estándar del curso LCA425 de Amerike: reglas para producir piezas audiovisuales con IA de forma responsable.
Es para el alumnado de LCA425 y para Claude, que carga estas reglas cuando trabajas en tu proyecto.
Incluye las reglas, los docs, la revisión automática de cada PR, el plugin de Claude Code y tarjetas para claude.ai.

## Instalar el plugin

En Claude Code:

    /plugin marketplace add daniknn/lca425-estandar
    /plugin install lca425@lca425
